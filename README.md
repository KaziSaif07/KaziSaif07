### 02 / SELECTED BUILDS

**📎 DropOnce — One-Time File Sharing Platform**
No-account file sharing: senders upload a file and get a 6-character share code; receivers download it once before it's permanently deleted. Auto-deletes after one download or 24-hour expiry, with uploads up to 500 MB.
**Stack:** Node.js · Express · Secure File Transfer

**📊 AI-Driven FinOps Dashboard**
An AI-powered dashboard for monitoring cloud spend, surfacing service-level cost breakdowns (including Varnish service usage), and flagging anomalies in spending patterns for faster cost optimization.
**Stack:** Python · Streamlit

**🚗 Car Rental Dashboard**
Responsive car rental management dashboard with dynamic filtering and data visualization for browsing and booking vehicles, with interactive charts to compare availability, pricing, and status at a glance.
**Stack:** Next.js · TypeScript · Tailwind CSS · API Integration
